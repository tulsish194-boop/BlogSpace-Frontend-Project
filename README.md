# BlogSpace — Beginner Frontend Project

## Files
- `index.html` — Home page
- `login.html` — Login form UI
- `register.html` — Registration form UI
- `dashboard.html` — Lists posts and allows deletion
- `create-blog.html` — Create/publish blog posts
- `style.css` — Responsive styles
- `app.js` — Frontend interactions and localStorage

## Run it
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click `index.html` to open it in Chrome, or open the folder in Visual Studio Code and use Live Server if installed.
4. Open Dashboard → Create blog to add a post.

## Important limitations
This is a frontend learning demo. Blog posts are stored in the same browser using localStorage. Login and Register only validate the form; they do not create secure accounts because no backend/database is included.

## Suggested submission
If your internship dashboard asks for a GitHub repository, create a repository named `blogspace-frontend`, upload all files, and submit the repository URL. If it asks for a deployed website link, deploy it with GitHub Pages or another static hosting service and submit that URL.
